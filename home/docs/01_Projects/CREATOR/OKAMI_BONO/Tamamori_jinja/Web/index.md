# ホームページの作成
魂守神社のホームページを作るにあたって、進め方や作ってみたい内容をまとめる。

## 進め方
ホームページの開発を進めつつ、開発がある程度できて公開できる段階になったら、動画でストーリー解禁。

ホームページの開発期間と動画のストーリー・動画作成の期間を考慮すると、最初は2〜3くらい機能を非公開で開発を進め、動画作りをした方が良さそう。
1機能につき動画の数は多めにしたいところではある。

ローカルで開発し、testで本番環境に近い環境でテスト、最終的に本番環境でup。

## 作りたい機能
- おみくじ
- 神使とお喋り
- イケボノオオカミと写真を撮る
    - アカウント連携
    - ガチャ機能（ガチャで撮れるフレームが増える、など）
