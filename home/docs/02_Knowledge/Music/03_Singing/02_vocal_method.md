# 02 発声方法
歌をうたう際、ある程度無意識に声の出し方をコントロールしているが、それぞれの声の特徴によって発声方法が異なる。発声をコントロールすることで歌声に表情がつき、いわゆる「棒読み感」がなくなる。

## 声帯閉鎖について
声帯閉鎖とは言葉通り声帯を閉じる技術のこと。習得すると声量を安定させたり、以下に挙げるような発声方法などの表現力をつけることができる。

しかし、声帯閉鎖によって声帯の開閉をコントールすることと喉を締める行為は別物であることに注意が必要。大きく息を吸って止めたとき、首周りの筋肉に力が入っている場合には喉を締めている可能性が高い。そうした発声を続けているとすぐに疲れて高い声が出なくなってしまったり、最悪の場合喉を痛めてしまう可能性があるため、変な癖がついてしまわないように注意。

#### 完全閉鎖
声帯を完全に閉じた状態。音は発せられない。

#### エッジボイス
エッジボイスは、「あ゛あ゛あ゛あ゛あ゛あ゛」といったように、声帯を閉じながら出す声のこと。ブツブツと途切れたように聞こえ、別名"Vocal fly"とも呼ばれる。

下の楽譜への書き込みを見ると、主にフレーズの頭で使用されることが多いようである。
