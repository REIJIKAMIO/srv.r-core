# レポートの書き方
mdファイル、レポートの書き方を以下に記載。

## mdファイルの記法
### 保存場所
レポートファイルは本ディレクトリ内の`posts`に格納。ファイル名は`yyyymmddHHMMSS_title.md`で統一。日本語文字は使用しない。

### ファイル内に記入する必須事項
以下の内容をファイルの文頭に記載。`<!--mote-->`以前の内容がリストに表示される仕様になっている。カテゴリは以前に使用したものを使用することを基本とし、不足した場合に新規で記事内に追加していく。現在のカテゴリ一覧は「カテゴリ」欄から確認できる。`updated`は後から内容を追記した際に日付を更新すること。

```markdown
---
date:
    created: 2026-09-20T12:00:00
    updated: 2026-09-20T12:00:00
categories:
    - カテゴリ1
    - カテゴリ2
---

# title

概要文

<!-- more -->
```
