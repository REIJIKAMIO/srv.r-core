# REI開発
チャットGPTと対話しながらプログラムを組んでいるが思考負けして今何を作っていて、何が作れていないのか曖昧になりつつある。

<!-- more -->
## できていること
できること/できないことベースで進めており、何が作りたいというものがない状態で進めているのは原因のひとつでもあるが、
- キャラ設定
- DOCS
- Knowledge
を読んで返答はできている。そのほか
- 外部URLの情報を取得し、要約、おすすめは提案のベースはできている
## できていないこと
- 情報のチャンク化
- おすすめのUI
- 設定情報の追記(こっちがやること)
- 会話をもとに返答
## 情報の住み分け
- DOCS:自分が独自で調べてること
- Knowledge:REIのクロールで調べてること
- Canon:世界観設定やタロットなど定義されていること
- RECOMMEND: クロールしたときにみつけたおすすめ
